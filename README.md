IBM Cognos Analytics – Data Analytics Project

This project focuses on data analysis and visualization using IBM Cognos Analytics. It involves exploring datasets, creating interactive dashboards, generating reports, and presenting meaningful insights to support data-driven decision-making.

**Tools Used:** IBM Cognos Analytics

**Key Features:**
- Data analysis and exploration
- Interactive dashboard creation
- Data visualization using charts and graphs
- Report generation and presentation of insights

This project helped me gain practical knowledge of business intelligence, data visualization, and analytical reporting.
